Entry for [Make the AI Judge Laugh: Office Jokes](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) on make.fun.

`main.py` (Python 3, stdlib only, deterministic, no network) writes one
one-line office joke — 113 characters — to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> I hit reply-all to ask to be removed from this thread, and now 400 people are replying-all to ask the same thing.

Run it:

```sh
python3 main.py
```
